# My Hyprland Setup

Base consigliata: simple-hyprland su CachyOS.

## Ordine consigliato
1. Installa simple-hyprland
2. Installa i pacchetti in manifests/pacman-native.txt
3. Installa gli AUR in manifests/pacman-aur.txt
4. Esegui ./install.fish

## Note
- Pensato per CachyOS + Hyprland
- Include config personali per hypr, waybar, rofi, wlogout, kitty, dunst
- Potrebbero servire font Nerd Font e wallpaper inclusi nella repo
